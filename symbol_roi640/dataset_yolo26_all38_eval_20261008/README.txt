한 개의 총 mAP만으로 실제 도면 성능을 판단하지 마세요.

같은 도면 안의 영역 분리이며 추정 PDF 좌표/수동 대응의 한계는

7/11/12/14 개별 캡처는 학습에서 제외하여 기존 영역 검증 정책을 유지합니다.

새 증강 및 모델 학습은 실행하지 않았습니다.
