# 샘플 도면 설명문 텍스트 복구

최종 파일: `symbols_59_text_checked.dwg`

`symbols_59_literal_headings.dwg`는 윤곽선만 보고 제목을 잘못 단정한
이전 시험 결과다. 최종 결과나 웹 변환에 사용하지 않는다.

캡션 제목 `부품명`과 작업 안내 제목 `작업 주의`는 주변의 부품번호·
`CONNECTOR NO`·작업 지시 문장을 함께 읽어 복원한 문맥 판독이다.
원본 PDF에는 해당 글자의 유니코드가 없으므로 원래 문자 코드를
직접 확인한 결과로 취급하지 않는다.

기존 DWG의 심볼 블록 59개, 부자재 표 MTEXT 155개, 회로 표 MTEXT 720개,
심볼 캡션 31줄, 작업 안내 5줄을 유지했다. PDF 원문을 확대해서 확인한
설명문·호출문·표 제목 13줄을 `ADDITIONAL_EDITABLE_TEXT` 레이어에 더했다.
대응하는 원본 폴리선 449개는 삭제하지 않고
`ADDITIONAL_TEXT_ORIGINAL_OUTLINES` 레이어로 옮겼다.

이전 단계의 캡션·부자재 표·작업 안내 원본 레이어와 새 원본 레이어를
AutoCAD `-LAYER OFF`로 명시적으로 끄고 저장했다. 저장된 DWG를 다시
열어 네 레이어의 OFF 상태와 MTEXT·블록 개수를 확인했다. 기존 생성
코드에도 같은 레이어 명령을 추가했다.

부자재 표의 기존 OCR MTEXT도 확대 PDF 셀과 대조했다. `YAZAK1`처럼
문자를 잘못 읽거나 부품번호의 숫자 `0`을 `O`로 읽은 등 확실한 오류
32개를 같은 자리에서 수정했고, 저장된 DWG를 다시 열어 32개 문자열을
확인했다. 원본 폰트에서 `O`와 `0`을 구별하기 어렵거나 원본 자체에
특수기호가 혼합된 코드 필드는 추측해 고치지 않았다.

확정하지 않은 셀: 30행 `DB PART NAME`의 `MATH-OO1`, 2행 같은 열의
`EMB11O`, 10행 `DB PART DESC`의 제품 코드에 있는 `O/0`, 그리고
28·9·7·5행 `DB PART DESC`의 구분기호가 섞인 원본 문자열이다.
이 셀들은 기존 MTEXT를 유지했다. 다른 열에 동일한 코드가 없거나
원본 글꼴이 두 문자를 구별하지 못해 임의의 값으로 교체하지 않았다.

길이 숫자와 원형 번호는 이번 범위에서 제외했다. 부자재 표 27행은
PDF에서 취소선이 그어진 행이므로 활성 부품으로 오인되지 않도록 원본
상태를 유지했다. 이 결과는 동일한 샘플 PDF를 검증한 파일이며, 다른
도면의 모든 폴리선 문자를 자동 복구하는 일반 모델은 아니다.
